# 部署与初始化

## 目录

- `docker-compose.yml`：MySQL、Redis、MinIO、Mailpit、后端、前端 Nginx。
- `server/Dockerfile`：后端 Spring Boot 镜像。
- `deploy/nginx/Dockerfile`：构建 `employee-web`、`admin-web` 并交给 Nginx 托管。
- `deploy/nginx/default.conf`：静态资源、`/api/`、`/ws/` 反向代理。
- `deploy/deploy.env.example`：部署变量样板。

## 启动

```bash
cp deploy/deploy.env.example deploy/deploy.env
docker compose --env-file deploy/deploy.env up -d --build
```

访问地址：

- 员工端：`http://localhost/`
- 管理端：`http://localhost/admin/`
- 后端健康检查：`http://localhost:8080/actuator/health`
- MinIO API：`http://minio.localhost/`
- MinIO 控制台：`http://localhost:9001/`
- Mailpit：`http://localhost:8025/`

## 初始化

数据库表由 Flyway 在后端启动时自动初始化。

初始化业务数据：

```bash
python3 server/scripts/dev/bootstrap_demo_data.py
```

初始化脚本默认连接：

```text
http://127.0.0.1:8080
```

## 变量

上线前修改 `deploy/deploy.env`：

```text
MYSQL_PASSWORD
MYSQL_ROOT_PASSWORD
MINIO_ROOT_USER
MINIO_ROOT_PASSWORD
MINIO_ENDPOINT
SPRING_MAIL_HOST
SPRING_MAIL_PORT
SPRING_MAIL_USERNAME
SPRING_MAIL_PASSWORD
WORKFORCE_IM_WEBSOCKET_ALLOWED_ORIGIN_PATTERNS
```

`MINIO_ENDPOINT` 必须是浏览器和后端容器都能访问的地址。生产环境建议使用对象存储域名。

## 常用命令

```bash
docker compose --env-file deploy/deploy.env ps
docker compose --env-file deploy/deploy.env logs -f server
docker compose --env-file deploy/deploy.env restart server
docker compose --env-file deploy/deploy.env down
```

清空本地数据：

```bash
docker compose --env-file deploy/deploy.env down -v
```
