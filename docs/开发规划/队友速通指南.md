# Workforce Hub — 项目速览

## 项目介绍

面向中小企业的智能人事协同平台。跟飞书/钉钉/企微不是同一条赛道——它们做通用协同的横切，我们做人事管理的纵深。核心差异就三个：**私有化自部署省钱、Agent 嵌入业务链路、同栈轻量不自建轮子**。

---

## 我们不跟飞书/钉钉/企微 —— 产品定位不同

它们的优势：协同体验好、生态成熟、用户量大。这是事实，不用回避。

我们的选择：

1. **成本**：飞书标准版免费，但知识库、云空间、审批专业版都额外付费。50 人企业一年轻松几万。我们 Docker Compose 一键部署到企业自有服务器，一次部署费用，无按人计费。

2. **数据安全**：数据存在企业自己的服务器上。文件存储支持 OSS 和本地部署灵活切换，向量化和 Agent 侧端可用本地 AI，信息不出企业内网。

3. **Agent 不是贴上去的聊天助手，是嵌进业务链路的**：审批流程有 Agent 预审节点，群组会话里 @Agent 能 RAG 知识问答，硬规则违规直接驳回，模糊边界转人工复核。

## 核心产品模块：AgentDAGflow

自研轻量化 DAG 工作流编辑器。跟 Coze、Dify 比，不是比谁功能多：

| | Coze | Dify | AgentDAGflow |
|---|---|---|---|
| 部署 | SaaS 付费调用 | Docker 需 Python 额外镜像 | 跟系统同一个 jar 包 |
| 技术栈 | Node.js | Python | Vue + Spring AI（跟系统同栈） |
| 系统数据 | 需 API 对接 | 需 API 对接 | tool 节点直接读用户余额/排班/审批状态 |
| 维护成本 | 依赖外部服务 | 多套语言异构 | 一套代码，一次部署 |

没有最好的产品，只有最合适的产品。AgentDAGflow 不做通用平台，只做 Workforce Hub 内部的工作流引擎，够用不画蛇添足。

---

## 如何介绍项目

### 三个核心点

1. **成本算账**：50 人企业，飞书知识库+审批专业版 ≈  数万/年，自部署一台 2 核 4G 服务器 ≈  3000千/年
2. **Agent 演示**：员工说"我想请假" → Agent 意图识别 → 展示余额+跳转按钮 → 提交审批 → Agent 预审校验附件 → 通过/驳回
3. **同栈架构**：Coze/Dify 部署需要额外环境，AgentDAGflow 跟系统一个 jar 包就跑起来了

## 项目现状

- 后端 Java 17 + Spring Boot 3.x + MyBatis-Plus + Flowable + Spring AI
- 前端 Vue 3 + TypeScript + Vite + Pinia（管理后台 + 员工端两个独立应用）
- 数据库 MySQL（业务）+ PostgreSQL+pgvector（向量检索）+ Redis（缓存/会话）
- 已完成 94 轮技术审查，文档体系完整

## 商业模型

- 开源版：基础功能免费
- 付费版：大版本买断制 + 按年订阅两种模式
- 大版本内的小版本和优化免费，跨大版本升级需付费
- 接受企业定制开发
