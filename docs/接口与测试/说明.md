# 接口与测试文档索引

本目录统一存放接口文档与测试用例，并按模块拆分维护。

当前清单：

- `认证模块/`
  - 认证接口文档与测试用例
- `组织模块/`
  - 组织模块查询接口、写侧接口的接口文档与测试用例
- `文件模块/`
  - 文件中心第一版接口文档与测试用例
- `审批模块/`
  - 员工端审批接口文档、测试用例与前端字段契约
- `假期模块/`
  - 假期账户接口文档与测试用例
- `考勤模块/`
  - 考勤基础配置、打卡、日结果与异常接口文档与测试用例
- `会话模块/`
  - 员工端会话、群治理、消息、WebSocket 推送与智能体会话的接口文档和测试用例
- `智能体模块/`
  - 智能体治理、授权、任务、工具调用与审计的接口文档和测试用例
- `hub-web接口需求表-1.0.0.md`
  - hub-web 画布实现过程中发现的后端数据/接口缺口与字段级规格
- `hub-web接口文档-1.1.0.md`
  - hub-web 新增接口的已实现版本说明

维护约定：

- 新模块优先创建 `docs/接口与测试/<模块>/`
- 接口文档命名建议为 `接口文档_<模块><主题>.md`
- 测试用例命名建议为 `接口测试用例_<模块><主题>.md`
- 系统级接口目录继续维护在 `docs/架构与设计/接口与事件清单.md`
