# 文档目录说明

`docs/` 目录现在只保留总索引和分类目录，后续新增文档优先进入对应类别，不再直接散落在根目录。

## 当前分类

- `产品与业务/`
  - 平台导图、原始脑图、项目确认记录等业务总纲材料
- `架构与设计/`
  - 技术栈、后端骨架、核心表结构、状态机、权限矩阵、接口与事件清单
- `开发规划/`
  - 开发流程总览、开发落地清单等推进型文档
- `API与测试/`
  - 按模块继续拆分 API 文档与测试用例，当前已落 `module-org/`
- `开发日志/`
  - 按模块或主题记录真实开发过程
- `审查/`
  - 按审查轮次归档审查结论
- `申报材料/`
  - 比赛、申报、展示类材料

## 维护约定

- `docs/` 根目录原则上只保留 `README.md` 和分类目录
- 新的 API 文档与测试用例统一放入 `docs/API与测试/<module>/`
- 新的开发日志统一放入 `docs/开发日志/`
- 新的审查文件统一放入 `docs/审查/`
- 如果某一类文档继续增长，优先先建子目录，再新增文件

1. `docs/产品与业务/平台总导图.md`
