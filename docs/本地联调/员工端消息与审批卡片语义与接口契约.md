# 员工端消息页 & 审批中心 — 语义与接口契约

> 适用页面：`/hub/messages`（`hub/views/MessagesView.vue` + `hub/styles/messages.css`）、`/hub/approvals`（`hub/views/ApprovalsView.vue` + `hub/styles/approvals.css`）
> 画布基准：Ardot「员工端-新消息」3:2204、「员工端-审批中心」8:34，1440×900，挂 HubShell（顶导 + 左侧图标栏），页面无滚动
> 用途：明确各区域的语义、字段、状态、交互与待接接口，作为后续联调依据。
> 更新日期：2026-10-14

## 路由与壳层约定

| 项 | 约定 |
| --- | --- |
| 壳层 | 两页均挂 `HubShell`（提供顶部导航 64px + 左侧图标栏 64px），页内内容区 ≈ 784px（900 视口），高度按比例分配、禁止页面级滚动 |
| 旧路由 | `/messages*` → `/hub/messages`；`/todos*` → `/hub/approvals`（均已重定向，旧 MessagesSection/TodosSection 不再直达） |

| 认证 | HubShell onMounted 校验 `session.initialized`，未登录跳 `/login` |

# 一、消息页（/hub/messages）

## 数据流总览

| 数据 | 来源 | 说明 |
| --- | --- | --- |
| 会话列表 | `im.loadConversations()` → `shell.mergeBackendConversations` | 挂载时加载，默认选中第一个会话 |
| 会话消息 | `im.loadMessages(id)` + `im.loadConversationDetail(id)` + 已读回写 `im.updateReadPosition` | 切会话时同步 |
| 实时消息 | WebSocket `/ws/employee/im`（`useImSocket`，30s 心跳、指数退避重连） | onMounted 时 `connectImSocket()` |
| 联系人 | `session.loadOrgProfile()` | 会话成员选择器、头像兜底 |

## 区域 1：会话列表（344px）

**语义**：全部会话的入口，支持筛选、搜索、新建。

| 元素 | 含义 | 数据来源 | 备注 |
| --- | --- | --- | --- |
| 新建会话 + | 打开新建会话弹窗（私聊/群聊/AI 三模式） | `im.startPrivateConversation` / 群创建 / AI 会话创建 | 群聊支持多选成员；AI 支持搜索（`agents.list`） |
| 筛选 chips | 全部 / @我 / 单聊 / 群组 / AI | 前端过滤 | @我 = `hasMentionMe`；群组 = `kind=team`；AI = `kind=agent`；单聊 = `private/approval/attendance/file` |
| 搜索框 | 按标题/摘要模糊过滤 | 前端过滤 | — |
| 会话项 | 头像 + 名称(+人数) + 摘要 + 时间 + 未读徽标(99+ 封顶) + 置顶 | `shell.conversations` | 激活态浅蓝底（--hub-sky） |
| 空态 | 「没有匹配的会话」 | — | — |

## 区域 2：聊天窗口（弹性宽）

**语义**：当前会话的消息流与发送区。

| 元素 | 含义 | 数据来源 | 备注 |
| --- | --- | --- | --- |
| 聊天头 | 标题 + 元信息（日期/人数）+ WS 断连提示 | `activeConversation` | 「连接已断开」仅在 WS 断开时显示 |
| 群管理按钮 | 仅群聊显示，打开群管理弹窗 | — | 弹窗含群名编辑、成员查看、添加成员、保存 |
| 消息流 | 系统消息行 / 流程卡 / AI 知识卡 / 气泡 | `activeConversation.messages` | 复用 `MessageBubble`/`ConversationProcessCard`/`KnowledgeAnswerCard` 组件 |
| 引用条 | 引用消息预览 + 取消 | `quotedMessagePreview` | — |
| 输入区 | 附件按钮 + 文本输入 + @AI 按钮 + 发送 | `im.sendMessage`（文本）、`uploadImMessageAttachment` + `im.sendFileMessage`（附件） | Enter 发送；@ 提及人名高亮预览 |

**消息操作菜单**（气泡右键/更多）：复制、引用、撤回（2 分钟内自己发的）/删除。转发、收藏、提醒、翻译为旧壳能力，**本版未迁移**，见待接清单。

## 区域 3：会话详情栏（300px）

**语义**：当前会话的档案与上下文，按会话类型切换。

| 类型 | 内容 | 数据来源 |
| --- | --- | --- |
| 群聊 team | 群成员头像墙（前 12）+ 人数 + 退出群聊 | `im.detailsByConversation[id].members`；退出 = `leaveActiveGroup` |
| AI 会话 agent | 快捷提问 chips（点击填入输入框） | `activeConversation.panel.tasks` 兜底，无数据显示提示文案；**知识库列表无接口，未渲染** |
| 私聊/其他 | 会话信息摘要 | `activeConversation.subtitle/summaryBody` |

## 弹窗

| 弹窗 | 语义 | 状态 |
| --- | --- | --- |
| 新建会话 | 私聊选人 / 群聊群名+多选 / AI 搜索选择 | ✅ 已接通 |
| 群管理 | 群名编辑保存、成员列表、添加成员 | ✅ 已接通；移除成员入口暂缺（API 已有 `removeGroupMembers`） |
| @提及个人卡 | 被提及人简卡 | ⚠️ 简化版（旧壳的加好友/发私聊未迁移） |
| 文件预览 | 附件预览 | ⚠️ 简化为新窗口打开下载链接（旧壳预览面板未迁移） |

# 二、审批中心（/hub/approvals）

## 数据流总览

| 数据 | 来源 | 说明 |
| --- | --- | --- |
| 待我审批 | `workflow.todos()` | 不分页，客户端分页（8 条/页） |
| 我发起的 | `workflow.requests({pageNo,pageSize,status,bizType})` | 服务端分页（8 条/页） |
| 审批动作 | `workflow.approveTask(taskId)` / `rejectTask(taskId, {comment})` | 驳回必须填原因（弹窗收集） |
| 撤回 | `workflow.withdrawRequest(requestId, {comment})` | 仅进行中单据显示撤回按钮，必填说明 |

## 区域 1：页头

**语义**：页面定位 + 高频动作入口。「发起审批」打开类型选择（请假/报销/加班/用印 2×2 网格），**表单为占位实现**（toast 提示），待接 `submitLeaveRequest` / `submitGenericRequest` 等提交接口与表单页。

## 区域 2：指标卡 ×4

| 卡片 | 含义 | 数据来源 | 口径备注 |
| --- | --- | --- | --- |
| 待我审批 | 待办总数 | `todos.length` | 精确 |
| 我发起 · 进行中 | 未完结单据数 | 当前页 `!finishedAt` 计数 + 总条数 | ⚠️ 进行中数为**当前页口径**，准确值需后端统计字段 |
| 本月已审批 | 本月完结数 | 当前页 `finishedAt` 本月前缀 | ⚠️ 同上，页口径 |
| 平均处理时长 | 完结单平均耗时 | 当前页 `finishedAt-submittedAt` 均值 | ⚠️ 页口径；有数据即显示 |

## 区域 3：审批列表（弹性宽）

**语义**：三个页签的流程清单 + 筛选 + 搜索 + 分页。

| 元素 | 含义 | 数据来源 |
| --- | --- | --- |
| 页签 | 待我审批(带计数徽标) / 我发起的 / 抄送我 | 抄送我**无接口**，空态「即将上线」 |
| 类型筛选 | 按单据类型过滤（选项从当前数据动态提取） | 前端过滤 |
| 状态筛选 | 仅「我发起的」页签显示 | 前端过滤 |
| 搜索 | 待我审批搜标题/摘要；我发起的搜标题/单号 | 前端过滤 |
| 审批单-待办 | 类型图标 + 标题 + 摘要·提交时间 + 加急标 + 驳回/同意 | `WorkflowTodoResponse` |
| 审批单-我的 | 类型图标 + 标题 + 单号·时间·当前节点 + 状态胶囊 + 撤回 | `WorkflowRequestSummaryResponse` |
| 分页器 | 总数 + 上/下页 | 待办客户端分页；发起的服务端分页 |

**类型图标映射**（图标语义规则）：请假 CalendarCheck / 报销 Receipt / 加班·补卡 Timer / 用印 Stamp(暖色) / 通用 FileCheck。

**状态胶囊**：通过/完成 → 绿；驳回/撤销/撤回 → 红；进行中 → 蓝。

## 区域 4：右栏（336px）

| 卡片 | 内容 | 数据来源 |
| --- | --- | --- |
| AI 预审概览 | 本周预审 / 通过率 / 硬规则拦截 | ⚠️ **全部占位「—」**，无统计接口；卡片注明「预审统计接口接入后展示」；审批单的「AI 预审通过/中」标签同理未实现（todos 响应无该字段） |
| 审批效率 | 平均处理时长（同指标卡口径）/ 最长等待（最老待办小时数，≥24h 标橙）/ 本周催办「—」 | 前两项本地可算，催办无接口 |
