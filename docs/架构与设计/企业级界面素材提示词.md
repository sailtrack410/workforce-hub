# 企业级 UI 素材占位符与生成提示词

## 使用规则

- 页面占位符统一使用 `data-ui-asset="<ASSET_ID>"`，素材文件名使用同一 ID 的小写 kebab-case。
- 生成图禁止包含文字、Logo、水印、二维码、品牌商标和可辨识的真实员工面孔。
- 登录主视觉只承担氛围和业务语义，表单、表格、组织树、DAG、图表、文件类型和状态反馈继续由组件、Lucide 与 CSS 实现。
- 生成结果先保存到 `ui-assets/generated/`，压缩和裁切后再复制到对应前端的 `src/assets/`。
- 浅色与深色界面都必须保证主体可见；页面叠加的标题和按钮由 HTML 渲染，不让模型生成文字。

## 交付检查

- 登录图桌面裁切时不得遮挡表单，移动端裁切后不得只剩背景。
- WebP 单张建议控制在 `350 KB` 内，并提供 `srcset` 或按视口加载。
- Agent 头像需分别导出，不使用包含多个头像的整图。
- 所有素材必须有明确 `alt`；纯装饰素材使用空 `alt` 和 `aria-hidden="true"`。
- 替换占位符后删除对应可见开发标记，但保留 `data-ui-asset` 便于追踪。
