# 节点编辑器侧边栏配置

## 节点类型列表

| 类型 | 标识 | 说明 |
|------|------|------|
| START | 开始 | 流程起点 |
| LLM | 大模型 | 调用大语言模型 |
| TOOL | 工具 | 调用外部工具 |
| CONDITION | 条件判断 | 分支逻辑 |
| INTENT | 意图识别 | 识别用户意图 |
| APPROVAL | 审批预审 | 审批决策 |
| KNOWLEDGE | 知识检索 | 知识库查询 |
| FORM_EXTRACT | 表单提取 | 提取表单字段 |
| SUMMARY | 摘要生成 | 内容摘要 |
| TRANSFORM | 数据整理 | 数据格式转换 |
| END | 结束 | 流程终点 |

---

## 通用配置项（所有节点）

- 节点 ID
- 类型（只读）
- 输出变量（START/END/CONDITION 除外）
- 输入字段列表（key + label + ref）
- 输出字段列表（key + label）
- 输入/输出类型 （string、json等格式类型）
- 连线列表
- 删除节点按钮

---
