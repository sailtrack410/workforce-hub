# 桌面端 UI 设计规范

## 目标

桌面端采用钉钉式工作台风格：左侧稳定导航，右侧高密度任务区，界面清晰、轻量、可快速扫描。所有头像、企业标识、Agent 标识优先使用可配置图片；没有图片时使用默认图标，不使用文字占位。

## 颜色

- 主题色：`#1677FF`，用于主按钮、当前导航、关键链接和选中状态。
- 成功色：`#1FAD66`，用于通过、完成、在线。
- 警示色：`#FF9F18`，用于待处理、风险提醒。
- 错误色：`#D93026`，用于失败、驳回、危险操作。
- 中性色：`#1F2329` 到 `#F7F8FA`，用于正文、辅助文本、边框和页面背景。

## 间距

- 页面边距：桌面端 `24px`。
- 页面栅格间距：`16px`。
- 面板内边距：`16px`。
- 表单行间距：`12px`。
- 列表行内边距：`12px 14px`。
- 控件图标与文字间距：`6px`。

## 圆角

- 输入框、按钮、标签：`6px`。
- 面板、弹窗、表格容器：`8px`。
- 头像和状态点：圆形。
- 禁止大面积卡片使用超过 `8px` 的圆角。

## 字号

- 页面标题：`22px`，字重 `700`。
- 面板标题：`16px`，字重 `700`。
- 正文：`14px`。
- 辅助说明：`12px`。
- 表格表头：`12px`，字重 `700`。

## 组件

- 按钮高度：`36px`，主按钮蓝底白字，次按钮白底灰边，危险按钮红底白字。
- 输入框高度：`36px`，聚焦时蓝色描边和浅蓝投影。
- 表格行高：`44px` 起，鼠标悬停使用浅蓝背景。
- 标签使用轻背景和深文字，不使用大面积高饱和色块。
- 弹窗宽度按内容控制，常规确认 `400px`，表单弹窗 `720px` 到 `860px`。

## 头像和品牌图形

- 员工头像接口：`avatarAttachmentRefId`。
- 会话头像接口：`avatarFileId`。
- Agent 头像接口：`avatarAttachmentRefId`。
- 企业 Logo：前端组件预留 `logoUrl`，后续可接系统设置接口。
- 默认头像：用户使用用户图标，Agent 使用机器人图标，企业使用楼宇图标。
- 禁止用姓名首字、企业简称、Agent 编码作为图片占位。

## 文案

- 保留“Agent”作为产品名，其余操作尽量用口语化中文。
- “审批治理”改为“审批设置”。
- “系统治理”改为“系统记录”。
- “文件清理”改为“文件空间”。
- “DAG”在按钮中改为“流程编排”。
- “幂等键”面向普通用户时改为“防重复编号”。
- “Dry-run”改为“模拟清理”。

## 验收

- 桌面端员工端和管理端所有一级页面都能正常打开。
- 不出现文字头像占位。
- 核心控件圆角、边距、字号符合本规范。
- 单测、构建和 Playwright 可视化检查通过。
