# 架构图产物索引

本目录存放架构图、数据流图、工作流图、状态图与时序图的生成产物。同一版本按 `版本号+图名` 命名：`.json` 为规格、`.html` 为可交互渲染、`.png`/`.svg` 为导出图、`-视觉校验*` 为自动截图证据。

| 版本 | 图名 | 文件 |
|------|------|------|
| 1.0.0 | 系统架构图 | `1.0.0系统架构图.html`、`1.0.0系统架构图.json` |
| 1.0.0 | 功能架构图 | `1.0.0功能架构图.html`、`1.0.0功能架构图.json` |
| 1.0.0 | 知识库入库数据流图 | `1.0.0知识库入库数据流图.html`、`1.0.0知识库入库数据流图.json` |
| 1.1.0 | 请假审批数据流图 | `1.1.0请假审批数据流图.html`、`.json`、`.png`、`.svg` |
| 1.0.0 | 请假审批工作流图 | `1.0.0请假审批工作流图.html`、`1.0.0请假审批工作流图.json` |
| 1.0.0 | 请假状态生命周期图 | `1.0.0请假状态生命周期图.html`、`1.0.0请假状态生命周期图.json` |
| 1.0.0 | 知识库问答时序图 | `1.0.0知识库问答时序图.html`、`1.0.0知识库问答时序图.json` |

版本规则：

- 图的结构或节点有实质变更时递增次版本号，如请假审批数据流图从 1.0.0 更新到 1.1.0
- 只调整样式或修复渲染问题时递增修订号，更新后保留旧版本文件，不覆盖
- 视觉校验产物与所属图共用版本号，如 `1.1.0请假审批数据流图-视觉校验-1440x900-深色.png`
