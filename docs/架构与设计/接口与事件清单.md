## 一、目的与范围

这份文档用于把前面已经确认的业务模块、表结构、状态机、权限矩阵和技术架构，进一步落成第一版开发可直接参考的接口与事件清单。

当前目标不是把每个字段都写成接口文档，而是先明确：
- 第一版有哪些核心 HTTP 接口族
- 员工端和后台端的接口边界如何划分
- 哪些变更需要实时推送
- 哪些业务动作需要沉淀成内部领域事件

## 二、接口设计总约定

### 1. 命名空间约定
- 员工端接口前缀：`/api/employee`
- 后台端接口前缀：`/api/admin`
- WebSocket 入口建议：
  - `employee-web`：`/ws/employee`
  - `admin-web`：`/ws/admin`

### 2. 认证约定
- 员工端使用业务用户会话
- 后台端使用管理员会话
- 第一版采用服务端 Session
- 重要写接口必须校验登录态、权限、数据范围、对象状态

### 3. 响应约定

建议统一响应包：

```json
{
  "code": 0,
  "message": "ok",
  "data": {},
  "requestId": "xxx"
}
```

### 4. 分页约定

建议统一分页结构：

```json
{
  "pageNo": 1,
  "pageSize": 20,
  "total": 100,
  "list": []
}
```

### 5. 时间约定
- 接口时间统一使用 ISO 8601
- 日期字段使用 `YYYY-MM-DD`
- 日期时间字段使用带时区的字符串

### 6. 幂等约定
- 提交申请
- 发送消息
- 发起知识入库
- 创建 Agent 任务
- 人工确认 Agent 执行

以上接口建议支持 `Idempotency-Key` 或业务侧 `clientRequestId`

### 7. 文件上传约定

第一版建议采用“两段式上传”：

1. 向后端申请上传票据
2. 客户端直传 `LOCAL` 或 `MINIO`
3. 回调或确认生成 `sys_file_object`
4. 创建 `sys_attachment_ref` 关联到具体业务对象

文件中心补充约定：

- 物理去重以 `content_sha256 + file_size` 为准，文件名不参与物理去重
- 下载通过短期 `downloadTicket` 或预签名 URL，不直接暴露长期对象地址
- 新增上传需同时校验个人配额、空间配额、组织长期文件池和存储后端真实可用容量
- 回收站默认 30 天，无引用物理对象默认 7 天后清理

### 11. 关键请求体补充

#### 1. 上传完成确认

`POST /api/employee/files/confirm-upload`

```json
{
  "uploadTicketId": 1001,
  "objectKey": "employee/2026/05/01/xxx.pdf",
  "contentSha256": "9b7d...",
  "fileSize": 1048576,
  "ownerType": "doc_document",
  "ownerId": 3001,
  "displayName": "请假证明.pdf"
}
```

#### 2. 下载票据申请

`POST /api/employee/files/{attachmentRefId}/download-tickets`

```json
{
  "downloadType": "SINGLE"
}
```

#### 3. Agent 人工确认

`POST /api/employee/agent-tasks/{id}/confirm`

```json
{
  "approved": true,
  "comment": "同意继续执行"
}
```

#### 4. Agent 任务取消

`POST /api/employee/agent-tasks/{id}/cancel`

```json
{
  "reason": "当前业务已结束，无需继续执行"
}
```

#### 5. 后台上传完成确认

`POST /api/admin/files/confirm-upload`

请求体建议与员工端保持一致：

```json
{
  "uploadTicketId": 2001,
  "objectKey": "admin/2026/05/01/knowledge/xxx.pdf",
  "contentSha256": "f42a...",
  "fileSize": 2097152,
  "ownerType": "kb_document",
  "ownerId": 9001,
  "displayName": "员工手册.pdf"
}
```
