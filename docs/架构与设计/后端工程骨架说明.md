# 后端工程骨架说明

## 一、工程概况

- 项目根目录：`server/`
- 构建工具：Maven
- JDK：17
- Spring Boot：3.2.5
- 包名前缀：`com.workforcehub`

## 二、技术栈依赖

| 类别 | 技术选型 | 版本 |
| --- | --- | --- |
| 主框架 | Spring Boot | 3.2.5 |
| 安全 | Spring Security (JSON API 模式) | 随 Spring Boot |
| 会话 | Spring Session + Redis | 随 Spring Boot |
| ORM | MyBatis-Plus | 3.5.5 |
| 审批流引擎 | Flowable (仅 BPMN 流程引擎) | 7.0.1 |
| 实时通信 | Spring WebSocket (STOMP) | 随 Spring Boot |
| 数据库迁移 | Flyway | 随 Spring Boot |
| 对象存储 | MinIO | 8.5.7 |
| API 文档 | SpringDoc OpenAPI | 2.3.0 |
| 工具库 | Hutool + Lombok | 5.8.25 |
| 数据库驱动 | MySQL Connector/J + PostgreSQL | 随 Spring Boot |

## 四、运行角色分离

通过 Spring Profile 区分 `backend-api` 与 `backend-worker`：

| Profile | 职责 | 默认端口 |
| --- | --- | --- |
| `api` | HTTP 接口、WebSocket、同步业务事务、事件发布、任务建单 | 8080 |
| `worker` | Agent 任务轮询执行、知识入库 Pipeline、定时任务、超时扫描 | 8081 |

启动方式：
```bash
# 开发档（单进程承担全部职责）
java -jar workforce-hub.jar

# 生产档 - API 节点
java -jar workforce-hub.jar --spring.profiles.active=api

# 生产档 - Worker 节点
java -jar workforce-hub.jar --spring.profiles.active=worker
```

- 仓库根目录提供 `.env.example`，当前收口已落地的 MySQL、Redis、SMTP、Flowable、MinIO 变量样板。
- `.env.example` 只作为变量清单和占位示例，不会被 Spring Boot 自动加载；本地运行时需通过 IDE、shell 或 Docker Compose 注入。
- 网易 163 SMTP 联调时，需至少使用 `MAIL_PORT=465`、`MAIL_SMTP_AUTH=true`、`MAIL_SMTP_SSL_ENABLE=true`。

## 六、线程池隔离

| 线程池 | Bean 名称 | 核心/最大 | 队列容量 | 用途 |
| --- | --- | --- | --- | --- |
| 业务异步 | `bizExecutor` | 4 / 16 | 256 | 通用异步任务 |
| Agent 执行 | `agentExecutor` | 2 / 8 | 64 | Agent 模型推理与工具调用 |
| 知识入库 | `kbIngestExecutor` | 2 / 4 | 32 | 文档解析、切片、向量化 |

三个线程池均使用 CallerRunsPolicy 拒绝策略，避免任务丢失。

## 七、SPI 接口设计

SPI 层解决模块间循环依赖，各模块面向接口编程：

```
module-workflow ──→ WorkflowAgentPreReviewTrigger ──→ module-agent 实现
module-agent   ──→ WorkflowAgentResultCallback   ──→ module-workflow 实现
module-im      ──→ ImAgentTriggerService          ──→ module-agent 实现
module-agent   ──→ ImAgentResultCallback          ──→ module-im 实现
module-agent   ──→ KnowledgeSearchService         ──→ module-kb 实现
module-agent   ──→ OrgQueryService                ──→ module-org 实现
module-agent   ──→ LeaveQueryService              ──→ module-leave 实现
module-agent   ──→ AttendanceQueryService         ──→ module-attendance 实现
```
