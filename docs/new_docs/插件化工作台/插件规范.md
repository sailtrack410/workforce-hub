# 插件化工作台 - 插件规范

## plugin.json 规范

### 完整字段

```json
{
  "id": "leave-plugin",
  "name": "假期管理",
  "description": "提供假期余额、请假申请等功能",
  "version": "1.2.0",
  "provider": "workforce-hub",

  "sdkVersion": "1.0.0",
  "minHostVersion": "1.0.0",
  "maxHostVersion": "2.0.0",
  "javaVersion": "17",
  "frontendProtocol": "1.0",

  "type": "UI",

  "dependencies": [
    {
      "pluginId": "org-plugin",
      "minVersion": "1.0.0",
      "maxVersion": "2.0.0"
    }
  ],

  "capabilities": [
    "LEAVE_READ",
    "LEAVE_DEDUCT"
  ],

  "visibility": [
    { "scopeType": "ALL" }
  ],

  "actions": [
    {
      "actionCode": "query-balance",
      "name": "查询假期余额",
      "description": "查询指定用户的假期余额",
      "inputSchema": {
        "userId": { "type": "number", "description": "用户ID", "required": true },
        "leaveTypeId": { "type": "number", "description": "假种ID", "required": true }
      },
      "outputSchema": {
        "balance": { "type": "number", "description": "可用余额（分钟）" }
      },
      "requiredCapability": "LEAVE_READ",
      "defaultTimeout": "5s",
      "idempotent": true
    }
  ],

  "frontend": {
    "entry": "frontend/index.js",
    "integrity": "sha384-xxx"
  },

  "signature": {
    "signerId": "workforce-hub-official",
    "algorithm": "SHA256withRSA"
  }
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | string | 是 | 插件ID（唯一） |
| name | string | 是 | 插件名称 |
| version | string | 是 | 插件版本（语义化） |
| sdkVersion | string | 是 | 依赖的SDK版本 |
| minHostVersion | string | 是 | 最低宿主版本 |
| maxHostVersion | string | 否 | 最高宿主版本 |
| javaVersion | string | 是 | Java版本要求 |
| type | string | 是 | UI 或 FUNCTIONAL |
| dependencies | array | 否 | 依赖的其他插件 |
| capabilities | array | 否 | 申请的能力列表 |
| visibility | array | 是 | 可见范围 |
| actions | array | 否 | 动作列表（PluginActionHandler） |
| frontend | object | UI插件必填 | 前端配置 |
| signature | object | 是 | 签名信息 |

## JAR 包规范

### 必需文件

```
plugin.json              # 在JAR根目录
db/migration/*.sql       # 迁移脚本
frontend/index.js        # UI插件的前端代码
```

### 安全要求

- 最大包大小：50MB
- 防止 Zip Slip：解压路径校验
- 防止压缩炸弹：解压后大小校验
- 防止重复条目：文件名去重
- 迁移脚本：只允许 SELECT/INSERT/UPDATE/DELETE/ALTER/CREATE/DROP

## 能力编码规范

| 能力前缀 | 说明 | 示例 |
|----------|------|------|
| LEAVE_ | 假期相关 | LEAVE_READ, LEAVE_DEDUCT |
| ATTENDANCE_ | 考勤相关 | ATTENDANCE_READ |
| WORKFLOW_ | 审批相关 | WORKFLOW_SUBMIT, WORKFLOW_APPROVE |
| ORG_ | 组织相关 | ORG_READ |
| FILE_ | 文件相关 | FILE_UPLOAD, FILE_DOWNLOAD |
| AGENT_ | Agent相关 | AGENT_CHAT |
| NOTIFICATION_ | 通知相关 | NOTIFICATION_SEND |

## 版本号规范

使用语义化版本：`主版本.次版本.补丁版本`

- 主版本：不兼容的API变更
- 次版本：向后兼容的功能新增
- 补丁版本：向后兼容的问题修复

示例：`1.0.0`, `1.2.3`, `2.0.0`
