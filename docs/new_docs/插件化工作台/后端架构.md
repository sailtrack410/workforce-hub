# 插件化工作台 - 后端架构

## 技术选型

| 组件       | 技术        | 版本   |
|------------|-------------|--------|
| 插件框架   | PF4J        | 3.15.0 |
| 主框架     | Spring Boot | 3.2.5  |
| 数据库     | MySQL 8.x   | -      |

不引入 pf4j-spring，手动管理 Spring 子 Context。

---

> **接口契约**：详见 [plugin-sdk契约.md](./plugin-sdk契约.md)。简记：插件→宿主用 `HostService`（不继承 ExtensionPoint），宿主→插件用 `PluginExtension`（继承 ExtensionPoint），HTTP→插件用 `PluginActionHandler`。

## 插件管理器

```java
@Component
public class PluginManager {

    private final org.pf4j.PluginManager delegate;
    private final PluginSignatureVerifier signatureVerifier;
    private final PluginVersionService versionService;
    private final PluginFlywayMigrator flywayMigrator;

    public PluginManager(
            PluginSignatureVerifier signatureVerifier,
            PluginVersionService versionService,
            PluginFlywayMigrator flywayMigrator) {
        this.signatureVerifier = signatureVerifier;
        this.versionService = versionService;
        this.flywayMigrator = flywayMigrator;

        // 使用自定义 PluginFactory 注入 PluginContext
        WorkforcePluginFactory factory = new WorkforcePluginFactory(contextFactory);
        this.delegate = new DefaultPluginManager() {
            @Override
            protected PluginFactory createPluginFactory() {
                return factory;
            }
        };
    }

    // 安装插件（带签名校验）
    public PluginInfo install(Path jarPath) {
        // 1. 签名校验
        signatureVerifier.verify(jarPath);

        // 2. 版本兼容性校验
        PluginDescriptor desc = parseDescriptor(jarPath);
        versionService.checkCompatibility(desc);

        // 3. 加载插件
        String pluginId = delegate.loadPlugin(jarPath);

        // 4. 执行数据库迁移
        flywayMigrator.migrate(pluginId, jarPath);

        // 5. 启动插件
        delegate.startPlugin(pluginId);

        return buildPluginInfo(pluginId);
    }

    // 启用插件
    public void enable(String pluginId) {
        // 检查依赖是否已启用
        checkDependencies(pluginId);
        delegate.startPlugin(pluginId);
        updateStatus(pluginId, "ACTIVE");
    }

    // 停用插件（等待请求排空）
    public void disable(String pluginId, Duration drainTimeout) {
        // 1. 标记为停用中，拒绝新请求
        updateStatus(pluginId, "DISABLING");

        // 2. 等待进行中的请求完成
        drainActiveRequests(pluginId, drainTimeout);

        // 3. 停用插件
        delegate.stopPlugin(pluginId);

        // 4. 释放资源（线程池、ClassLoader等）
        releaseResources(pluginId);

        updateStatus(pluginId, "STOPPED");
    }

    // 卸载插件（保留数据库数据）
    public void uninstall(String pluginId) {
        // 1. 先停用
        if (isRunning(pluginId)) {
            disable(pluginId, Duration.ofSeconds(30));
        }

        // 2. 卸载插件（不删除数据库）
        delegate.unloadPlugin(pluginId);

        // 3. 更新状态
        updateStatus(pluginId, "UNINSTALLED");
    }
}
```

## 签名校验

```java
@Component
public class PluginSignatureVerifier {

    private final List<TrustedSigner> trustedSigners;

    public void verify(Path jarPath) {
        // 1. 计算SHA-256
        String sha256 = calculateSha256(jarPath);

        // 2. 读取JAR中的签名文件
        byte[] signature = readSignature(jarPath);

        // 3. 验证签名
        boolean valid = trustedSigners.stream()
            .anyMatch(signer -> signer.verify(sha256, signature));

        if (!valid) {
            throw new PluginSignatureException("插件签名验证失败");
        }
    }
}

public record TrustedSigner(
    String signerId,
    PublicKey publicKey,
    String algorithm
) {
    public boolean verify(String data, byte[] signature) { ... }
}
```

## 版本校验

```java
@Component
public class PluginVersionService {

    private final String hostVersion;
    private final String sdkVersion;

    public void checkCompatibility(PluginDescriptor desc) {
        // 检查SDK版本
        if (!isSdkCompatible(desc.getSdkVersion())) {
            throw new PluginVersionException(
                "插件SDK版本不兼容: " + desc.getSdkVersion());
        }

        // 检查宿主版本
        if (!isHostCompatible(desc.getMinHostVersion(), desc.getMaxHostVersion())) {
            throw new PluginVersionException(
                "宿主版本不兼容: 需要 " + desc.getMinHostVersion() + "-" + desc.getMaxHostVersion());
        }
    }

    private boolean isSdkCompatible(String pluginSdkVersion) {
        // 主版本必须相同，次版本向后兼容
        return getMajorVersion(sdkVersion).equals(getMajorVersion(pluginSdkVersion))
            && getMinorVersion(sdkVersion) >= getMinorVersion(pluginSdkVersion);
    }
}
```

## Flyway 迁移

```java
@Component
public class PluginFlywayMigrator {

    private final DataSource dataSource;

    public void migrate(String pluginId, Path jarPath) {
        // 1. 清理pluginId中的非法字符
        String safeId = sanitizePluginId(pluginId);

        // 2. 使用独立的history表
        String historyTable = "flyway_plugin_" + safeId;

        // 3. 验证表名安全（防止SQL注入）
        validateTableName(historyTable);

        // 4. 执行迁移
        Flyway flyway = Flyway.configure()
            .dataSource(dataSource)
            .locations("filesystem:" + jarPath.resolve("db/migration"))
            .table(historyTable)
            .baselineOnMigrate(true)
            .validateOnMigrate(true)
            .load();

        flyway.migrate();
    }

    private String sanitizePluginId(String pluginId) {
        // 只保留字母、数字、下划线
        return pluginId.replaceAll("[^a-zA-Z0-9_]", "_");
    }

    private void validateTableName(String tableName) {
        if (!tableName.matches("^[a-zA-Z0-9_]{1,64}$")) {
            throw new IllegalArgumentException("非法表名: " + tableName);
        }
    }
}
```

## 调用上下文绑定

```java
@Component
public class InvocationContextBinder {

    // HTTP请求绑定
    public InvocationContext bindFromRequest(HttpServletRequest request, String pluginId) {
        WfhUserDetails user = CurrentUserHolder.current();

        return InvocationContext.builder()
            .pluginId(pluginId)
            .userId(user != null ? user.getUserId() : null)
            .callerType(resolveCallerType(user))
            .requestId(request.getHeader("X-Request-Id"))
            .source(InvocationContext.TriggerSource.HTTP_REQUEST)
            .build();
    }

    // 定时任务绑定（插件身份）
    public InvocationContext bindForScheduledTask(String pluginId) {
        return InvocationContext.builder()
            .pluginId(pluginId)
            .userId(null)
            .callerType(InvocationContext.CallerType.PLUGIN)
            .requestId(UUID.randomUUID().toString())
            .source(InvocationContext.TriggerSource.SCHEDULED_TASK)
            .build();
    }

    // 事件回调绑定
    public InvocationContext bindForEventCallback(String pluginId, DomainEvent event) {
        return InvocationContext.builder()
            .pluginId(pluginId)
            .userId(resolveUserId(event))
            .callerType(InvocationContext.CallerType.PLUGIN)
            .requestId(event.eventId())
            .source(InvocationContext.TriggerSource.EVENT_CALLBACK)
            .build();
    }
}
```

## 通用调用网关

```java
@RestController
@RequestMapping("/api/plugin-gateway")
public class PluginGatewayController {

    private final PluginManager pluginManager;
    private final InvocationContextBinder contextBinder;

    @PostMapping("/{pluginId}/actions/{actionCode}")
    public ServiceResult<Object> executeAction(
            @PathVariable String pluginId,
            @PathVariable String actionCode,
            @RequestBody Map<String, Object> params,
            HttpServletRequest request) {

        // 1. 绑定调用上下文（不可伪造）
        InvocationContext ctx = contextBinder.bindFromRequest(request, pluginId);

        // 2. 获取插件的ActionHandler
        PluginActionHandler handler = pluginManager.getActionHandler(pluginId, actionCode);

        // 3. 校验权限
        checkPermission(ctx, handler.getDescriptor().requiredCapability());

        // 4. 执行动作
        return handler.execute(ctx, params);
    }
}
```

## 宿主服务示例

```java
@Service
public class LeaveServiceImpl implements LeaveService {

    @Override
    public ServiceResult<LeaveDeductResult> deductBalance(
            InvocationContext ctx,
            Long userId,
            Long leaveTypeId,
            int minutes,
            String idempotencyKey,
            String operationReason,
            String relatedBizId) {

        // 1. 校验权限
        permissionService.checkPermission(ctx, "LEAVE_DEDUCT", userId);

        // 2. 检查幂等
        if (isDuplicateOperation(idempotencyKey)) {
            return ServiceResult.fail(ErrorCodes.DUPLICATE_OPERATION, "重复操作");
        }

        // 3. 执行扣减
        LeaveDeductResult result = doDeduct(userId, leaveTypeId, minutes);

        // 4. 记录审计
        auditService.log(ctx, "LEAVE_DEDUCT", userId, operationReason, relatedBizId);

        // 5. 记录幂等键
        saveIdempotencyKey(idempotencyKey);

        return ServiceResult.ok(result);
    }
}
```
