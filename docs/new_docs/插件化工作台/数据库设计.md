# 插件化工作台 - 数据库设计

## 插件注册表

```sql
CREATE TABLE sys_plugin (
    plugin_id         VARCHAR(64)  PRIMARY KEY,
    name              VARCHAR(128) NOT NULL,
    description       VARCHAR(512),
    version           VARCHAR(32)  NOT NULL,
    sdk_version       VARCHAR(32)  NOT NULL,      -- SDK版本
    min_host_version  VARCHAR(32),                 -- 最低宿主版本
    max_host_version  VARCHAR(32),                 -- 最高宿主版本
    java_version      VARCHAR(16)  DEFAULT '17',   -- Java版本
    type              VARCHAR(32)  NOT NULL,        -- 'UI' 或 'FUNCTIONAL'
    status            VARCHAR(32)  NOT NULL DEFAULT 'INSTALLED',
    jar_path          VARCHAR(512) NOT NULL,
    jar_sha256        VARCHAR(64)  NOT NULL,        -- JAR文件SHA-256
    signature         BLOB,                         -- 签名
    signer_id         VARCHAR(128),                 -- 签名者ID
    frontend_entry    VARCHAR(512),                 -- 前端JS入口
    frontend_sha384   VARCHAR(96),                  -- 前端文件SHA-384（SRI）
    provider          VARCHAR(128),
    error_message     TEXT,
    installed_at      DATETIME     NOT NULL,
    updated_at        DATETIME     NOT NULL
);
```

## 插件依赖关系

```sql
CREATE TABLE sys_plugin_dependency (
    plugin_id        VARCHAR(64) NOT NULL,
    depends_on       VARCHAR(64) NOT NULL,
    min_version      VARCHAR(32),              -- 最低版本要求
    max_version      VARCHAR(32),              -- 最高版本要求
    PRIMARY KEY (plugin_id, depends_on)
);
```

## 插件配置

```sql
CREATE TABLE sys_plugin_config (
    plugin_id        VARCHAR(64)  NOT NULL,
    config_key       VARCHAR(128) NOT NULL,
    config_value     TEXT,
    value_type       VARCHAR(32)  DEFAULT 'STRING',  -- STRING/INT/BOOL/SECRET
    default_value    TEXT,
    description      VARCHAR(256),
    requires_restart TINYINT      DEFAULT 0,          -- 修改后是否需要重启
    is_secret        TINYINT      DEFAULT 0,          -- 是否敏感配置
    PRIMARY KEY (plugin_id, config_key)
);
```

## 插件能力授权（替代roles字段）

```sql
CREATE TABLE sys_plugin_capability (
    plugin_id        VARCHAR(64)  NOT NULL,
    capability_code  VARCHAR(128) NOT NULL,     -- 能力编码（如 LEAVE_READ, LEAVE_DEDUCT）
    description      VARCHAR(256),
    PRIMARY KEY (plugin_id, capability_code)
);
```

## 插件可见范围

```sql
CREATE TABLE sys_plugin_visibility (
    plugin_id        VARCHAR(64)  NOT NULL,
    scope_type       VARCHAR(32)  NOT NULL,     -- ALL/MANAGER/DEPT/POSITION/USER
    scope_value      VARCHAR(128),              -- 部门ID/岗位ID/用户ID（ALL时为空）
    PRIMARY KEY (plugin_id, scope_type, scope_value)
);
```

## 动作权限表

```sql
CREATE TABLE sys_plugin_action_permission (
    plugin_id        VARCHAR(64)  NOT NULL,
    action_code      VARCHAR(128) NOT NULL,
    capability_code  VARCHAR(128) NOT NULL,     -- 执行此动作所需的能力
    PRIMARY KEY (plugin_id, action_code)
);
```

## Flyway 迁移策略

### 历史表命名规则

每个插件使用独立的 Flyway 历史表，表名格式：

```
flyway_plugin_{sanitized_plugin_id}
```

其中 `sanitized_plugin_id` 只保留字母、数字、下划线，最大64字符。

### 迁移脚本位置

插件 JAR 内的 `db/migration/` 目录：

```
leave-plugin.jar
├── plugin.json
├── db/
│   └── migration/
│       ├── V1__init_leave_tables.sql
│       └── V2__add_leave_columns.sql
└── frontend/
    └── index.js
```

### 迁移执行时机

1. 插件安装时：执行所有待迁移脚本
2. 插件升级时：执行新增的迁移脚本
3. 迁移失败：禁止启动插件，记录错误

### 迁移脚本命名

```
V1__init_leave_tables.sql
V2__add_leave_columns.sql
```

**注意**：不使用插件ID前缀，因为每个插件有独立的history表。

### 卸载策略

- 卸载插件时**不删除数据库表**
- 数据保留在原表，后续重装可复用
- 如需彻底清理，由管理员手动执行SQL

## 版本升级记录

```sql
CREATE TABLE sys_plugin_upgrade_history (
    id               BIGINT       PRIMARY KEY AUTO_INCREMENT,
    plugin_id        VARCHAR(64)  NOT NULL,
    from_version     VARCHAR(32),
    to_version       VARCHAR(32)  NOT NULL,
    upgrade_type     VARCHAR(32)  NOT NULL,     -- INSTALL/UPGRADE/DOWNGRADE
    status           VARCHAR(32)  NOT NULL,     -- SUCCESS/FAILED/ROLLBACK
    error_message    TEXT,
    upgraded_at      DATETIME     NOT NULL,
    INDEX idx_plugin_id (plugin_id)
);
```

## 生命周期状态表

```sql
CREATE TABLE sys_plugin_lifecycle (
    plugin_id        VARCHAR(64)  PRIMARY KEY,
    status           VARCHAR(32)  NOT NULL,     -- INSTALLED/ACTIVE/STOPPED/ERROR/DISABLING
    last_started_at  DATETIME,
    last_stopped_at  DATETIME,
    last_error_at    DATETIME,
    last_error_msg   TEXT,
    active_requests  INT          DEFAULT 0,    -- 当前活跃请求数
    restart_required TINYINT      DEFAULT 0,    -- 是否需要重启
    updated_at       DATETIME     NOT NULL
);
```
