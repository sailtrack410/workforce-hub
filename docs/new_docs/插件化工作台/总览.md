# 插件化工作台 - 总览

## 设计目标

将 Workforce Hub 的功能模块设计为可插拔的插件，支持：
- 后端 JAR 插件热加载（基于 PF4J）
- 前端组件动态注册与渲染（Host SDK 方案）
- 按角色过滤功能入口
- 插件生命周期管理（安装、启用、停用、卸载）

## 插件类型

| 类型     | 说明                      | 管理端       | 员工端               |
|----------|---------------------------|--------------|----------------------|
| UI插件   | 带前端组件，提供用户界面  | 显示管理入口 | 显示在工作台导航     |
| 功能插件 | 纯后端，提供API或定时任务 | 显示管理入口 | 不显示，但功能可用   |

示例：
- UI插件：假期管理（有余额页面、请假表单）
- 功能插件：自动考勤计算（定时任务，无页面）、消息推送网关（纯API）

## 插件状态机

```
┌─────────┐    上传     ┌──────────┐   启用    ┌─────────┐
│  未安装 │ ──────────→ │  已安装  │ ────────→ │  运行中 │
└─────────┘             │ (未启用) │           └─────────┘
                        └──────────┘               ↑  │
                             ↑                     │  │ 停用
                             │                     │  ↓
                        ┌──────────┐           ┌─────────┐
                        │  卸载中  │ ←──────── │  已停用 │
                        └──────────┘   卸载    └─────────┘
                                                  ↑  │
                                                  │  │
                                              ┌──────────┐
                                              │  异常    │
                                              │(启动失败)│
                                              └──────────┘
```

| 状态          | 值        | 说明               |
|---------------|-----------|--------------------|
| NOT_INSTALLED | -         | JAR未上传          |
| INSTALLED     | installed | JAR已上传，未启用  |
| ACTIVE        | active    | 正常运行中         |
| STOPPED       | stopped   | 手动停用           |
| ERROR         | error     | 启动失败或运行异常 |

## 状态颜色（管理端）

| 状态           | 颜色 | 图标 |
|----------------|------|------|
| 运行中         | 绿色 | ●    |
| 已停用         | 灰色 | ●    |
| 异常           | 红色 | ●    |
| 已安装(未启用) | 黄色 | ●    |

## 操作按钮映射

| 状态   | 可用操作         |
|--------|------------------|
| 运行中 | 停用、配置、卸载 |
| 已停用 | 启用、配置、卸载 |
| 异常   | 重试、停用、卸载 |
| 已安装 | 启用、卸载       |

## 设计规则

- 只显示**已启用且带前端的插件**（UI插件 + ACTIVE状态）
- 不显示插件状态（员工不需要知道）
- 不显示功能插件（纯后端的不出现）
- 按角色过滤（员工看不到管理类插件）
- 相同 `directory` 的插件自动归为一组
- 未匹配到已有目录的插件自动创建新分组
- 分组排序和组内排序由 `order` 字段控制
