# 插件化工作台 - 开发计划

## 可行性评估：6-7/10

首版定位为"可信、签名的内部插件平台"，不承诺第三方不可信插件隔离、完美热卸载和多节点同步。

---

| 阶段     | 时间    | 目标                           | 交付物                                     |
|----------|---------|--------------------------------|--------------------------------------------|
| 架构验证 | 第1周   | 验证PF4J+Spring Boot集成可行性 | plugin-sdk模块、PF4J PoC、Flyway验证       |
| 后端核心 | 第2-3周 | 生命周期管理、安全校验、配置   | 状态机、签名校验、Flyway、配置CRUD、审计日志|
| 管理端   | 第4周   | 插件管理页面                   | 上传/启停/配置/卸载/错误展示/权限码        |
| 员工端   | 第5周   | 动态插件加载、工作台入口       | 清单API、IIFE加载器、SRI校验、动态导航     |
| 样板插件 | 第6周   | 验证完整链路                   | 1个UI插件+1个功能插件+SDK示例              |

### 第1周：架构验证

- [x] 实现 `InvocationContext`（宿主绑定，不可伪造）
- [x] 实现 `PluginContext` 和 `WorkforcePlugin` 基类

- [x] 实现 `ErrorCodes`

## 关键约束

1. **不引入 pf4j-spring**：手动管理 Spring 子 Context
2. **不升级 Spring Boot**：保持 3.2.5
3. **不迁移现有模块**：两个月内不动考勤/假期/审批
4. **不做第三方沙箱**：首版只支持内部可信插件
5. **InvocationContext 由宿主绑定**：插件不可伪造
6. **所有写操作必须有幂等键**：防止重复操作
7. **首版单节点**：不支持多实例同步
