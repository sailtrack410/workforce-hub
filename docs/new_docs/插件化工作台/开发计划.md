# 插件化工作台 - 开发计划

## 可行性评估：6-7/10

首版定位为"可信、签名的内部插件平台"，不承诺第三方不可信插件隔离、完美热卸载和多节点同步。

## 关键约束

1. **不引入 pf4j-spring**：使用单一 `WorkforcePluginManager` 和构造器注入；v0.1 不创建插件 Spring 子 Context
2. **不升级 Spring Boot**：保持 3.2.5
3. **不迁移现有模块**：两个月内不动考勤/假期/审批
4. **不做第三方沙箱**：首版只支持内部可信插件
5. **InvocationContext 由宿主绑定**：插件不可伪造
6. **写操作使用明确重试契约**：事件订阅使用幂等键，配置使用版本与墓碑，管理员生命周期仅终态重试幂等；HTTP 插件动作自动幂等尚未实现
7. **首版单节点**：不支持多实例同步
