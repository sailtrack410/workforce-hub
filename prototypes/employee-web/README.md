# Workforce Hub 员工端前端原型

这是按项目文档先行做出的用户端静态原型，放在独立目录中，不改动现有后端。

当前正式员工端主线已经切到 `employee-web/` Vue 工程。`prototypes/employee-web/` 只作为历史设计稿和交互参考保留，不再作为正式开发入口继续承载业务接口、状态模型或真实联调逻辑。

## 覆盖范围

- 默认消息入口：一级功能栏、会话列表、聊天主区、右侧详情栏。
- 待办中心：申请、审批、文件、Agent 任务的混合待办。
- 文档与文件中心：个人云空间、配额、上传与下载语义。
- 工作台：请假、补卡、考勤、假期、审批、Agent 问答等入口。
- 我的：个人档案、直属上级、直属下级、账号安全。

## 查看方式

直接在浏览器打开：

```text
prototypes/employee-web/index.html
```

也可以用任意静态服务器托管该目录。

## 维护边界

- 正式源码以 `employee-web/src/` 为准。
- 本目录只保留静态设计参考，后续不再和 Vue 工程双轨同步演进。
- 本目录中的接口文案都是原型说明，不能作为后端 Controller 契约。
