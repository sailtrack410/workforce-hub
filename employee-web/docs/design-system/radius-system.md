# 圆角梯度

## 梯度

| Token | px | 场景 |
| --- | --- | --- |
| `radius-4` | 4 | 极小输入件、内嵌标签 |
| `radius-6` | 6 | 小元素、icon button、badge |
| `radius-8` | 8 | 默认卡片、列表项、输入框 |
| `radius-12` | 12 | 弹层、过程卡、消息气泡 |
| `radius-16` | 16 | 大容器、工作台统计卡、移动端底部 sheet |

## 约束

- 小元素默认 `radius-6`
- 卡片默认 `radius-8`，强调卡可上到 `radius-12`
- 主页面大容器和工作台英雄卡使用 `radius-16`
- Dialog / Drawer / 移动端详情层使用 `radius-12`

## 禁止项

- 不允许组件自己写 `10px / 14px / 18px / 20px` 这种游离圆角。
- 同一组件不同状态不靠圆角变化表达交互，只允许颜色、描边、阴影和位移变化。
