# 间距梯度

## 目标

所有 `padding / margin / gap` 必须命中固定梯度，避免不同页面自己微调出一堆看起来“差不多”的值。

## 梯度

| Token | px | 推荐场景 |
| --- | --- | --- |
| `space-4` | 4 | 图标与文字、细小内边距 |
| `space-8` | 8 | 小按钮、badge、chip |
| `space-12` | 12 | 表单项内部、紧凑列表 |
| `space-16` | 16 | 默认卡片内边距、小容器 |
| `space-20` | 20 | 中号区块、面板行距 |
| `space-24` | 24 | 大卡片、弹层内容区 |
| `space-32` | 32 | 页面分组、大区块间距 |
| `space-40` | 40 | 页面标题与主体之间 |
| `space-56` | 56 | 首页 hero、仪表板强分区 |

## 映射规则

- 输入框高度: 使用 `space-12 + space-16` 组合，不写裸高。
- 列表项默认内边距: `space-16`
- 过程卡默认内边距: `space-20`
- Drawer / Dialog 内容: `space-24`
- 页面主内容左右留白: `space-24` 到 `space-32`
- 工作台大卡之间: `space-24`

## 工程规则

- 不允许出现 `6 / 10 / 14 / 18 / 22 / 26 / 30` 这类游离值作为间距。
- 需要更松时优先提升到下一档，不允许在相邻两档之间插值。
