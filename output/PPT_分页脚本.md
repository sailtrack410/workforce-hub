### 第2页：痛点与市场空白（20秒）
**标题**：为什么不用飞书、钉钉、企微？  
**核心信息**：
- 通用协同平台的人事模块只是“标配”，无法满足专业人事业务深度需求
- AI 能力停留在简单问答，无法实现复杂审批预审、多工具调用、工作流编排
- 权限与安全模型粗粒度，无法满足企业级合规审计要求
- SaaS 标准化方案无法私有化部署，定制深度有限

**视觉**：左侧列出飞书/钉钉/企微的四个短板，右侧 workforce-hub 四个优势箭头指向

---

### 第3页：四维对比坐标图（25秒）
**标题**：四维能力对比：我们为什么不同  
**坐标图**（雷达图或四象限）：
- **X轴**：人事业务深度（考勤、假期、排班、入转调离、组织生命周期）
- **Y轴**：AI Agent 可编排性（可视化工作流、多节点组合、工具调用、版本管理）
- **Z轴1**：权限与安全粒度（三线权限裁剪、工具白名单、全链路审计）
- **Z轴2**：私有化与定制深度（独立部署、流程模板自定义、连接器扩展）

**数据点**：
- 飞书/钉钉/企微：集中在左下角（业务深度中、编排性低、安全中、定制低）
- Workforce-Hub：四个维度全满，形成完整的能力覆盖圈

**话术**：“通用平台在四个维度上都有明显短板，而我们的平台在每个维度都做到了企业级深度。”

### 第4页：平台定位与架构总览（30秒）
**标题**：一体化平台：从协同到智能人事  
**三层架构图**：
1. **前端层**：员工 Web 端 + 管理后台 + 小程序（统一业务能力）

**核心模块标签**：
- 组织与权限
- 考勤与排班
- 假期与余额
- 审批与流程
- 协同沟通（IM）
- **Agent 平台（核心创新）**
- 知识库与 RAG
- 连接器与凭证托管

**话术**：“我们不是简单的功能堆砌，而是通过模块化架构实现人事业务的全链路闭环。”

### 第5页：Agent 平台创新（40秒）
**标题**：AI Agent 平台：可视化编排与安全执行  
**核心创新点**（分三块展示）：

1. **生命周期管理**：
   - 草稿 → 测试 → 发布 → 停用 → 回滚
   - 版本化管理，发布后仍可回滚到历史版本

2. **五大能力组件**（发布时配置）：
   - 模型选择与路由
   - Prompt 模板
   - 工具绑定与白名单授权
   - 知识库 RAG 绑定
   - **工作流编排（DAG 可视化编辑器）**

3. **四种触发方式**：
   - 会话中 @Agent 触发
   - 审批流程节点触发（预审）
   - 定时任务触发
   - 事件驱动触发（入职/离职等）

**视觉**：左侧流程图展示生命周期，中间五个图标代表能力组件，右侧四个触发方式图标

### 第6页：三线权限裁剪（25秒）
**标题**：安全第一：三线权限裁剪机制  
**公式**：
```
最终执行权限 = Agent自身权限 ∩ 当前用户授权范围 ∩ 业务/知识范围
```

**三层解释**：
1. **Agent 自身权限**：后台配置的工具白名单、数据范围
2. **当前用户授权范围**：用户所在部门、角色、汇报关系
3. **业务/知识范围**：当前审批流程、知识库授权范围

**安全机制**：
- 硬规则违规 → 自动驳回
- 低置信度 → 转人工复核
- 高风险操作 → 人工兜底确认
- 全链路审计日志

**视觉**：三个相交的圆圈图，交集部分高亮为“最终执行权限”

---

### 第7页：DAG 工作流编辑器（30秒）
**标题**：可视化工作流编排：让 AI 按业务逻辑执行  
**功能亮点**：
- 10种节点类型：开始/结束、大模型、工具、条件判断、意图识别、审批预审、知识检索等
- 拖拽连线：直观构建复杂业务逻辑
- 节点配置：模型选择、提示词编辑、工具参数、数据源绑定
- 试运行与调试：单节点测试 + 全流程测试
- 版本对比与回滚

**典型场景**：请假审批工作流
```
开始 → 意图识别 → 条件分支 → 审批预审 → 条件判断 → 三种回复 → 结束
```

**话术**：“管理员无需编码，通过拖拽就能构建复杂的 AI 审批预审流程，大幅降低人工审批成本。”

## 演示部分（2分钟）脚本
**总时长：120秒**

### 阶段1：进入 Agent 管理（20秒）
- 登录管理后台
- 导航到 Agent 管理列表
- 选中“请假审批 Agent”
- 点击“编辑工作流”进入 DAG 视图

### 阶段2：DAG 编辑器核心操作（50秒）
- 展示画布上的请假审批工作流（已预配置）
- 拖拽添加一个新节点（如“表单提取”）
- 连线到现有流程
- 选中“审批预审”节点，展示右侧配置面板：
  - 模型选择下拉框
  - 数据源勾选（员工信息、假期余额、政策）
  - 审核提示词编辑框
  - 置信度阈值设置
- 点击节点右上角“试运行”按钮，输入测试数据，展示输出

### 阶段3：全流程测试（40秒）
- 点击顶部“运行流程”按钮
- 在输入框输入：“我想请三天年假，去海南旅游”
- 点击运行，展示执行步骤：
  - 意图识别：识别为“请假申请”
  - 条件分支：进入请假审批分支
  - 审批预审：调用工具查询员工余额、检查政策
  - 条件判断：根据置信度决定通过/转人工
  - LLM 回复：生成友好回复
- 展示最终回复：“您的请假申请已通过，剩余年假余额 5 天。”
- 强调：“整个过程无需人工干预，AI 自动完成策略校验与回复。”

### 阶段4：收尾（10秒）
- 返回 Agent 列表
- 强调：“管理员可以像这样快速配置各种业务场景的 AI Agent”
- 结束演示，准备 Q&A

## 关键提示
1. **PPT 节奏**：第5页（Agent平台）和第7页（DAG编辑器）是核心记忆点，不要压缩
2. **演示准备**：
   - 提前登录后台，打开请假审批 Agent 的 DAG 页面
   - 确保后端服务正常运行，测试数据就绪
   - 练习拖拽、连线、配置的流畅操作
3. **话术衔接**：PPT 最后一句自然过渡到演示：“接下来我将实际展示...”
4. **时间控制**：演示阶段严格计时，如果超时则跳过部分配置细节，直接运行流程展示结果
